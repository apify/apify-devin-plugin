# Changelog

All notable changes to the **Apify for Devin** plugin are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — Initial Devin release

### Added

- `apify` MCP server entry in `.mcp.json` pointing to `https://mcp.apify.com/?client=devin+plugin` (streamable HTTP).
- `.devin-plugin/plugin.json` manifest with plugin metadata.
- Apache-2.0 license.
